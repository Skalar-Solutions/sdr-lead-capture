RINGKASAN
---------
Extension ini scrape data bisnis dari Google Maps, menyimpannya lokal di
browser, lalu mengekspornya sebagai CSV. Tidak ada API, tidak ada server,
tidak ada token, tidak ada request keluar.

Fokusnya cuma satu: scrape -> CSV. Template kolom CSV bisa diubah di satu file
(kita isi nanti sesuai kebutuhan sales).

CARA PAKAI
----------
1. Buka Google Maps, klik satu tempat (jangan cuma hover).
2. Kotak capture terbuka otomatis. Kalau tidak, klik ikon extension di toolbar
   atau pill "SDR Capture" di kanan bawah.
3. Data langsung terbaca: nama, kategori, alamat, telepon, website, rating,
   jumlah review, dan link Maps.
4. Klik "Simpan ke CSV".
5. Ulangi untuk tempat lain.
6. Klik "Data" (popup) atau ikon clipboard (drawer) untuk buka halaman hasil.
7. Klik "Download CSV".

BULK SCRAPE
-----------
Dari halaman hasil pencarian (daftar bisnis di panel kiri):

1. Klik tombol "Ambil Semua" di kanan bawah.
2. Pilih batas 20/50/100, lalu "Mulai Ambil".
3. Extension auto-scroll daftar, membuka tiap tempat, dan extract datanya
   dengan jeda acak 0,6-1,3 detik per tempat.
4. Setelah selesai, muncul checklist. Tempat yang sudah ada ditandai
   "Sudah ada"; yang gagal dibaca ditandai "Gagal dibaca".
5. Centang yang mau disimpan, lalu "Simpan ke CSV".
6. Tombol "Berhenti" menghentikan proses dan tetap menyimpan hasil yang sudah
   terbaca.

Tab Maps harus tetap aktif selama proses. Batas maksimal 100 tempat per run.

CSV yang diekspor berisi semua baris yang belum dihapus. Setelah download,
data tetap tersimpan lokal sampai dihapus manual.

TEMPLATE CSV
------------
File: apps/extension/lib/csv-template.ts

Semua kolom diatur di array CSV_COLUMNS. Setiap item punya:
  { header: "Nama Kolom", value: (capture) => "nilai" }

Field yang tersedia di setiap Capture:
  capturedAt, companyName, category, address, phone (digits only), website,
  socialType, socialUrl, instagram, rating, reviewsCount, mapsUrl,
  isSocialMediaOnly, websiteStatus, digitalGaps, services, priority,
  picName, picRole, notes, whatsapp

Catatan migrasi & filter:
- readCaptures() otomatis menormalisasi record lama (sebelum 1.0.6) lewat
  normalizeCapture() sehingga field tagging selalu terisi aman tanpa crash.
- Nomor telepon dinormalisasi menjadi angka murni (digitsOnly).
- Bisnis tanpa kontak sama sekali (phone, whatsapp, instagram, socialUrl, dan
  website kosong semua) dilewati (isCaptureUseful -> hasAnyContact). Selama ada
  salah satu kontaknya, tetap di-scrape.

Dua format CSV yang didukung:
1. CRM_COLUMNS (13 kolom, crm-contact-YYYY-MM-DD.csv)
2. SDR_DETAILED_COLUMNS (21 kolom, sdr-leads-lengkap-YYYY-MM-DD.csv)

Kolom CSV mengikuti crm-contact-template.xlsx (13 kolom, urutan sama):

  *Nama, Sapaan, URL Foto, *Tipe Kontak, Grup Kontak, Perusahaan,
  Alamat Penagihan, Negara, Provinsi, Kota, Email, Nomor Telepon,
  Tanggal Lahir (dd/mm/yyyy)

Mapping:
  *Nama             <- nama bisnis
  *Tipe Kontak      <- "Vendor" (konstanta DEFAULT_CONTACT_TYPE)
  Grup Kontak       <- kategori Maps
  Perusahaan        <- nama bisnis
  Alamat Penagihan  <- alamat Maps
  Negara            <- "Indonesia" (konstanta DEFAULT_COUNTRY)
  Nomor Telepon     <- telepon Maps

Kosong karena tidak ada di Maps:
  Sapaan, URL Foto, Provinsi, Kota, Email, Tanggal Lahir

Data scrape lain (website, sosmed, rating, link Maps) TIDAK diekspor karena
template CRM tidak punya kolomnya. Kalau importer menerima kolom tambahan,
tambahkan di akhir array CSV_COLUMNS.

Setelah mengubah template:

  pnpm install
  pnpm build
  pnpm zip

Zip baru muncul di apps/extension/.output/.

PENYIMPANAN DATA
----------------
- Lokasi: chrome.storage.local, key "sdr_captures"
- Tidak ada data yang dikirim keluar.
- Uninstall extension = data hilang. Download CSV dulu.
- Data terikat ke profil Chrome di device itu (tidak sync antar device).

SMOKE TEST MAPS ASLI
--------------------
Jalankan manual sebelum rilis (butuh internet):

  pnpm build
  pnpm smoke:maps

Varian opsional:

  SMOKE_SEARCH_URL="https://www.google.com/maps/search/steakhouse+jakarta?hl=en" \
    pnpm smoke:maps
  SMOKE_SEARCH_URL="https://www.google.co.id/maps/search/steakhouse+jakarta" \
    pnpm smoke:maps

Script membuka Google Maps asli, memilih tempat pertama, menyimpan, lalu
menyimpan ulang untuk memastikan dedupe bekerja. Gagal = exit non-zero.
Bukti hasil: artifacts/smoke-maps.png dan artifacts/smoke-maps.json.

DESAIN UI
------------------
Sumber token: packages/ui/src/styles/tokens.css

- Warna : netral mono; satu accent "signal" (lime) untuk fokus, HOT, dan
          highlight kecil. Aksi utama memakai hitam/putih.

- Border: selalu 1px; focus ring 2px.
- Shadow: hanya shadow-lg untuk elemen mengambang; kartu memakai border.

BATASAN / CATATAN
-----------------
1. Scraper bergantung pada class DOM Google Maps. Kalau Google mengubah markup,
   perbaiki selector di entrypoints/content/scraper.ts. Bulk scrape juga
   bergantung pada `div[role=feed]` dan link `/maps/place/` di
   entrypoints/content/bulk.ts.
2. Bulk scrape membuka tempat satu per satu dengan jeda acak, maksimal 100 per
   run. Jangan klik/scroll Maps selama proses dan gunakan jumlah wajar.
3. Auto-detect bergantung pada event klik/URL Maps. Kalau tidak terbuka, klik
   pill "SDR Capture" atau refresh.
4. Dedupe otomatis aktif. Tempat dikenali dari place ID di link Maps; kalau
   link tidak lengkap, fallback ke nama + telepon + alamat. Capture ulang
   tempat yang sama tidak menambah baris.
5. Tidak ada fitur edit. Kalau salah, hapus baris lalu capture ulang.
6. Bundle total ~904 KB (content script 287 KB, content CSS 119 KB karena font
   Inter di-inline untuk shadow root, shared chunk 304 KB).
7. Zip rilis 1.0.5 sudah berisi auto-detect, bulk scrape, perbaikan P0/P1,
   icon baru, dan UI refresh (mono + accent lime, Inter, radius/border/font-size
   terbatas). Regenerate dengan `pnpm build && pnpm zip` + update release/
   sebelum distribusi.
